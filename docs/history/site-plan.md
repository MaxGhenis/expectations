# Site plan

`site/` is the deployable static root: the tracker at `/` (`index.html` +
`data.js` generated by `gen_data.py` from `outputs/`), the working paper at
`/paper/` (hand-written wrapper embedding the Quarto render in `/paper/web/`
— the paper-embed pattern; rebuild with `scripts/build_paper.sh`, bump the
`?v=` revision in the wrapper, `tests/test_paper_embed.py` locks the
lockstep). Serve with any static server; no build step, no dependencies.

## Current state

Five views on the full 38-combination matrix (decomposition, consensus fan,
calibration, term structure, scores), live survey × variable × horizon
controls, SD vs pooled-IQR and Q1-vs-all-rounds toggles, crosshair
tooltips, a data table per view, light/dark from one token block, and
URL-hash deep links (`#view=…&survey=…&variable=…&horizon=…`). Palette:
the dataviz reference instance, slots 1–3 (validated both modes) — swap to
`@policyengine/ui-kit` tokens only if the repo lands under PolicyEngine.
